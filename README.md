# Wireless-Audio-Transmission-System-using-ESP32
Designed and built a half-duplex wireless walkie-talkie system using ESP32 microcontrollers.
 The project integrated I2S microphone and speaker modules for high-quality digital audio acquisition and playback. Leveraging peer-to-peer wireless communication, I implemented real-time audio streaming, packet buffering, and hardware interrupts to achieve low-latency, reliable voice transmission
